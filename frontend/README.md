# RepairFlow AI

RepairFlow AI is a world-class, premium SaaS-grade web application designed for TV repair shop workflow management. 

## Features
- **Ultra-Premium UI/UX:** Built with glassmorphism, animated gradients, particle effects, and Framer Motion transitions.
- **Dashboard Overview:** Real-time metrics, revenue tracking, and recent jobs overview.
- **Interactive Kanban Board:** Drag-and-drop repair queue management.
- **Analytics Engine:** Visual breakdown of completion rates, brand statistics, and technician efficiency using Recharts.
- **Customer Messaging:** Integrated WhatsApp interface for automated and manual customer updates.
- **AI-Ready Form:** Add repair jobs with predictive text and AI autofill capabilities.
- **Dark Mode:** Stunning deep black and cyber blue/purple theme.

## Tech Stack
- Next.js 14 (App Router)
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
- Shadcn UI
- Lucide React

## Getting Started

1. Navigate to the frontend directory:
```bash
cd frontend
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## Project Structure
- `/src/app`: Next.js App Router pages (Landing Page, Dashboard, Repairs, Analytics, Messages, Settings).
- `/src/components/layout`: Sidebar and Header.
- `/src/components/ui`: Reusable design system components (Button, Card, Input, Badge).
- `/src/lib`: Utilities for styling and API functions.
